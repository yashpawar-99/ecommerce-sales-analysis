# E-Commerce Sales Analysis

## Project Overview

This project analyzes an e-commerce sales dataset to understand sales performance, regional performance, customer behavior, customer segments, and sales trends over time.

The goal of this project is to transform raw sales data into meaningful business insights using Python and data analysis techniques.

---

## Objectives

- Analyze overall sales performance
- Identify the best-performing product categories and sub-categories
- Compare sales across different regions
- Analyze customer purchasing behavior
- Identify repeat customers and high-value customers
- Compare customer segments
- Analyze yearly and monthly sales trends
- Identify important business insights from the data

---
